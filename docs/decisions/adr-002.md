# ADR-002: Mock Mode para Desenvolvimento

## Status
**Aceita** — Ativo em produção.

## Contexto
O desenvolvimento precisa funcionar sem conexão com Supabase (offline, demos, testes rápidos).

## Decisão
Implementar `mockDb` em `src/lib/supabase.ts` que replica a API do Supabase usando `localStorage`.

## Implementação
```typescript
// Detecção automática
const isMockMode = !url || url.includes('placeholder');

// mockDb expõe a mesma interface
mockDb.get(table)      // → { data: [...] }
mockDb.set(table, data) // Persiste no localStorage
```

- Dados persistidos com prefixo `qualitrack_mock_`
- Usuários padrão pré-cadastrados (admin, qualidade, suporte, gestores)
- Autenticação por comparação direta de email/senha

## Consequências
- ✅ Desenvolvimento sem dependência de serviço externo
- ✅ Demos instantâneas sem setup
- ⚠️ Duplicação de lógica CRUD (mock vs real)
- ⚠️ Mock não replica RLS, triggers ou Edge Functions
- ⚠️ Possibilidade de divergência de comportamento mock/prod

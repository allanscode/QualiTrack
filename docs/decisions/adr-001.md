# ADR-001: Migração Firebase → Supabase

## Status
**Aceita** — Migração concluída.

## Contexto
O projeto foi inicialmente construído sobre Firebase (Firestore + Firebase Auth). Durante o desenvolvimento, foi decidido migrar para Supabase por:
1. Necessidade de banco relacional (PostgreSQL) para queries complexas
2. RLS nativo no PostgreSQL para segurança granular
3. Edge Functions (Deno) para lógica server-side segura
4. Melhor custo-benefício para o volume esperado

## Decisão
Migrar completamente para Supabase (Auth + PostgreSQL + Edge Functions).

## Consequências
- ✅ Banco relacional com JOINs e queries complexas
- ✅ RLS nativo para segurança por row
- ✅ Edge Functions com service role key para operações admin
- ✅ Melhor tooling (SQL editor, dashboard)
- ⚠️ Lock-in no Supabase (mitigável por ser PostgreSQL padrão)
- ⚠️ `firestore.rules` permanece no repositório como artefato legado

## Artefatos Legados
- `firestore.rules` — Regras Firestore antigas, **não utilizadas**
- Referências a Firebase em comentários antigos

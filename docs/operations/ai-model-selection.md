# Modelo OpenRouter das avaliações

Administradores escolhem o modelo principal em **Administração → Central de IA → Automações**. A busca usa o catálogo ao vivo do OpenRouter e aceita apenas IDs que constem no catálogo com entrada de texto e saída somente de texto. Os preços exibidos são os metadados atuais do catálogo, por milhão de tokens; o selo **Grátis** exige preços de entrada e saída iguais a zero. Mesmo modelos gratuitos podem ter limites de requisição do provedor e gerar avaliações de qualidade diferente.

Sem busca, o seletor mostra uma lista curta de IDs presentes no catálogo atual: pagos `z-ai/glm-5.3-flash`, `google/gemma-4-31b-it`, `google/gemini-3.8-flash`; gratuitos `z-ai/glm-5.3-flash:free`, `google/gemma-4-31b-it:free`, `google/gemma-4-26b-a4b-it:free`, `nvidia/nemotron-3.5-lightning:free`, `nvidia/nemotron-3-nano-30b-a3b:free` e `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free`. A busca continua permitindo qualquer outro ID válido do catálogo. Gemini 3.8 Flash só tem endpoint pago no OpenRouter; não há `google/gemini-3.8-flash:free` na lista. As respostas continuam sendo JSON validado pela aplicação; o cliente Chat Completions não exige suporte de `response_format: json_schema` do provedor. Modelos gratuitos podem ter limites de uso, e os provedores NVIDIA podem registrar prompts: use esses endpoints de teste apenas com dados autorizados para o provedor.

A seleção fica em `public.ai_model_config` (`id = 'default'`), com leitura via RLS para administradores ativos e escrita apenas pela Edge Function. A `helpdesk-queue` verifica o papel no banco e valida novamente o ID contra o catálogo antes de salvar; clientes autenticados não recebem permissão de escrita direta. A chave OpenRouter permanece exclusivamente em Supabase Secrets ou no ambiente local. Sem registro de configuração, a Edge Function usa `z-ai/glm-5.3-flash`; o runner `production-pending-reevaluation.mjs` usa seu padrão anterior `google/gemma-4-31b-it`. A Edge Function lê a configuração do projeto em que está implantada; o runner lê o registro do projeto develop.

A migração `20261019000006_ai_model_config.sql` deve ser aplicada antes de ativar o painel. Esta alteração não aplica a migração nem executa avaliações.
